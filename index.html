Design skills // for the course

The design skill stack.

Seven skills that take an interface from brief to shipped, and the workflow that chains them. A working stack, built on the best open-source design skills. This page is what you can lift for your own setup.

01 The skills

impeccable-designVisual

The visual rulebook.

Reach for it on any UI work: type, color, spatial rhythm, UX writing, and the anti-slop rules that stop output from reading as AI-generated.

frontend-craftCode

Code-level craft.

When you are building the interface: interaction checklists, which modern CSS is production-safe, and component architecture (Radix, Base UI, shadcn).

emil-design-engMotion

Motion and interaction feel.

When deciding whether and how to animate: easing, timing, springs, gestures, and making motion feel premium instead of decorative. Based on Emil Kowalski's work.

review-animationsMotion QA

Adversarial motion audit.

Run it once motion is built. The stance is that approval is earned, not assumed.

design-tokensColor

Color and token system.

When setting up a palette: OKLCH scales in the W3C DTCG standard, exported to CSS variables, Tailwind, and JS. Steers you off the 2026 cream and AI-purple defaults.

accessibility-auditA11y

The accessibility gate.

Before shipping: WCAG 2.2 AA, the European Accessibility Act, APCA contrast, keyboard and screen-reader checks, each with a concrete fix.

ui-judgeJudge

The design judge.

To score a built UI: a deterministic anti-slop check plus an LLM vision judge, where the deterministic result binds the final verdict.

02 Download and install

Grab a skill, save the .md as ~/.claude/skills/<name>/SKILL.md, and it triggers automatically in your Claude Code.

impeccable-design.mdThe visual rulebook. Apache 2.0.↓ frontend-craft.mdCode-level interaction and CSS craft.↓ design-tokens.mdOKLCH / DTCG token systems.↓ accessibility-audit.mdWCAG 2.2 AA + EAA audit.↓ emil-design-eng + review-animationsThe two motion skills: get them from Emil Kowalski's repo.→

One skill, ui-judge, is kept private. Everything above is yours to use.

03 How they compose: brief to shipped

1
Brief, 3 Dials, slop test. Set audience, tone, and the variance / motion / density dials. impeccable-design
2
Tokens. OKLCH palette, avoid cream and purple. design-tokens
3
Build. Visual, craft, and motion together. impeccable-design + frontend-craft + emil-design-eng
4
Evaluate (free, always). A deterministic anti-slop check, axe WCAG 2.2 AA, and a motion review. review-animations
5
Judge (optional). A vision pass that scores the result. ui-judge
